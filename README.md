##Supply Chain Analytics

##Project Overview

An end-to-end Supply Chain Analytics project analyzing 30,000
orders to understand revenue, profitability, product performance,
inventory, shipping, and delivery performance.

##Tools & Technologies

- SQL
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- DAX
- Excel

##Dataset

The dataset contains 30,000 supply-chain order records covering:

- Order details
- Customers
- Regions
- Products
- Categories
- Suppliers
- Warehouses
- Quantity
- Cost and revenue
- Shipping methods
- Carriers
- Delivery dates
- Lead time
- Order status
- Inventory status

##Business Questions

###Sales & Profitability
- What is the total revenue?
- What is the gross profit?
- Which regions generate the highest revenue?
- Which products and categories perform best?

###Supply Chain
- Which orders are delayed?
- What is the overall delay rate?
- Which carriers have the highest delay rate?
- Which shipping methods have the longest lead time?

###Inventory
- What is the inventory status?
- Which products require attention?
- Which stock categories have the highest volume?

## Key Findings

- Total Orders: 30,000
- Total Revenue: $796.19M
- Gross Profit: $463.96M
- Profit Margin: 58.27%
- Delayed Orders: 2,421
- Delay Rate: 8.07%
